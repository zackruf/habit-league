# Code of Conduct

This is a small private project. Contributors are expected to work professionally, respectfully, and in good faith.

## Expectations

- Be respectful and direct
- Focus on solving problems, not blaming people
- Keep feedback constructive
- Protect confidential project information
- Respect the proprietary nature of the repository

## Unacceptable Behavior

- harassment or personal attacks
- sharing proprietary code or materials without permission
- intentionally disruptive collaboration
- exposing secrets or sensitive project information

Project participation is at the discretion of the repository owner.
